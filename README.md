# hxyfront-62007 植物标本馆 · 除虫封柜作业台

植物标本馆除虫封柜前端：预置三批标本与三个柜位，按「整批复核 → 整批除虫 → 整批封柜」流水线作业，全部数据本地持久化（刷新保留）。

## 业务规则

1. **整批复核**：同一批次内只要有一份未压制或鉴定存疑，整批退回复核；退回不改变任何标本与柜位。
2. **整批除虫**：仅复核通过的批次可执行；除虫记录按份留存，释放柜位后仍然保留（重复执行幂等）。
3. **整批封柜（原子拒绝）**：每份标本只能进入
   - 温湿度档一致（A/B/C）、
   - 剩余容量足够、
   - 未占用其他柜位
   的柜位；重复占用、档位不符、容量不足任一项出现，**整柜拒绝**，不写入任何占用。
4. **释放重封**：已封柜标本被改回鉴定存疑 / 未压制，或调整温湿度档时，先自动释放柜位（柜位记录标注移出原因与时间）、保留除虫记录，所在批次复核失效；补全后重新复核、封柜。
5. **筛选与同步**：按压制 / 鉴定 / 除虫 / 封柜状态、温湿度档、批次、关键词（采集号、物种、地点、海拔、生境）筛选；数据写入 `localStorage`，刷新后保留。

## 预置数据

- 第一批 · 莽山采集：2 份 A 档（合格）→ 柜 A-01
- 第二批 · 南岭采集：2 份 B 档（合格）→ 恰好占满柜 B-01，可演示容量拒绝
- 第三批 · 天目山采集：3 份 C 档，含 1 份未压制 + 1 份鉴定存疑 → 复核必退回；补全后封柜 C-01，错选 A/B 柜可演示档位不符整柜拒绝

## 技术栈

React 19 + Vite 7 + TypeScript（严格模式），无后端，状态经 reducer 原子更新并持久化到 `localStorage`。
